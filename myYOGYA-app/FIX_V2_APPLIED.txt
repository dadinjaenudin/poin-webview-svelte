SVELTE 5 REACTIVITY ISSUE:
In Svelte 5 dengan compatibility mode, `bind:` directive 
kadang tidak trigger reactivity dengan benar untuk props.

SOLUTION - CONDITIONAL RENDERING:
Menggunakan {#if} block untuk mount/unmount component.
Ini lebih reliable dan adalah best practice untuk modal components.

FLOW SEKARANG:
1. User click button → showScanner = true
2. {#if showScanner} becomes true → Scanner mounts
3. Scanner mounts dengan isOpen={true} → Component ready
4. Scanner menjalankan initScanner() → Camera starts
5. User close → showScanner = false → Scanner unmounts

BENEFITS:
✅ No reactivity issues
✅ Cleaner state management  
✅ Automatic cleanup on unmount
✅ Better performance (no hidden components)
