📋 TECHNICAL IMPLEMENTATION:

MenuGrid.svelte:
{#if showScanner}
  <Scanner 
    isOpen={true}           ← Always true when mounted
    onScanSuccess={...}
    onClose={...}
  />
{/if}

Scanner.svelte:
<div class="scanner-overlay" class:visible={isOpen}>
  <div id="qr-reader"></div>  ← Always in DOM when component mounted
</div>

CSS:
.scanner-overlay {
  opacity: 0;               ← Hidden by default
  pointer-events: none;
}
.scanner-overlay.visible {
  opacity: 1;               ← Show when isOpen=true
  pointer-events: auto;
}

🔄 FLOW:

1. User klik "Scan Member"
   ↓
2. showScanner = true
   ↓
3. {#if showScanner} → Component MOUNT
   ↓
4. Scanner mounts dengan isOpen=true
   ↓
5. onMount() runs
   ↓
6. DOM elements created (#qr-reader exists)
   ↓
7. Reactive statement: isOpen=true → initScanner()
   ↓
8. ✅ #qr-reader found!
   ↓
9. ✅ Scanner initializes
   ↓
10. ✅ Modal visible (opacity: 1)
    ↓
11. ✅ Camera starts

Close:
1. User klik "Kembali ke Menu"
   ↓
2. handleClose() calls onClose()
   ↓
3. onClose() sets showScanner = false
   ↓
4. {#if showScanner} → Component UNMOUNT
   ↓
5. onDestroy() cleans up
   ↓
6. ✅ Modal removed from DOM
